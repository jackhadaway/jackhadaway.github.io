# Academic website

Open index.html from the extracted folder for a local preview. All pages, styles, and artwork work offline. Test the YouTube embed from a served page because YouTube may require a web referrer. The Research page also has a direct viewing link.

## Make it yours

1. Replace [Your Name] throughout the seven HTML files.
2. Edit your bio in index.html and your research interests in research.html.
3. Replace the bracketed prompts in revision.html, artifact-1.html, artifact-2.html, and reflection.html as you complete the coursework. For a PDF, place it beside the HTML files and link to it with a relative filename. Check documents for private information before making them public.
4. The 3Blue1Brown video on Research is a placeholder. Keep the attribution and direct link if you use it, or update the embed URL, title, description, and direct link together.
5. Edit the color and font variables at the top of style.css. If you replace geometry.png, update its alternative text and width and height attributes.

## Publish on GitHub Pages

1. Create a public repository named YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your GitHub username.
2. Extract the ZIP. Upload the files directly to the root of the repository on the main branch. Confirm that index.html appears at the root.
3. Open Settings → Pages. Under Build and deployment, select Deploy from a branch. Choose main and /(root), then save.
4. Check the Pages deployment in Actions or Settings → Pages. Once deployed, open https://YOUR-USERNAME.github.io and test the links and video before submitting the URL.

[GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart)

## Template customization record

The site uses a shared header, navigation, main content area, and footer template. For the About page, the introductory text sits beside the image in a two-column layout. The final design uses large serif headings, a warm off-white background, a dark green header, and a custom parametric illustration sized to the image column. The main call to action uses a filled style and the added portfolio button uses an outline. Research provides an embedded video and external links. The Writing Portfolio index links to four new pages. Generic template elements such as a sidebar and social links are omitted.
